The **Pink Morsel Suite** is not just a graph—it is a **Strategic Decision Engine**. It bridges the gap between raw CSV files and quarterly boardroom presentations.

---

## 🛠️ Performance Architecture

### 🛡️ **Executive KPI Command Bar**
A high-contrast, card-based interface providing instant visibility into:
* **Total Revenue**: Dynamic aggregation of filtered datasets.
* **Period Growth**: Mathematical split-analysis of performance trends.
* **Market Leader**: Automated identification of the highest-performing regional asset.
* **Sales Volatility**: A risk-assessment metric using Standard Deviation to monitor demand stability.

### 📈 **Signal Intelligence (Trend Smoothing)**
By utilizing a **30-Day Rolling Average** toggle, users can suppress daily transactional "noise" to reveal the true macro-trend. This is paired with **Business Event Annotations** (e.g., Marketing Launches, Holiday Peaks) to provide historical context for sales spikes.

### 🎨 **Executive UI/UX**
* **Slate & Navy Theme**: Designed for visual comfort and professional authority.
* **Responsive Layout**: Built with a CSS-Grid foundation for seamless viewing.
* **Dynamic Insights**: A natural-language engine that interprets data trends in real-time.
